# 주간 보고 — STT 단어집 검수와 단계별 보정 시험

작성 안기겸 · 2026-11-21 · 11/20 멘토 피드백 대응 (단어집 발음 표기 검수, VAD → STT → 보정 단계별 시험)

### 한 일

**1. Transcribe 단어집 발음 표기 검수**

**결론: 단어집에는 글자 표기만 등록되어 있고, 발음 표기는 AWS가 지원하지 않아 검수 대상이 아닙니다.**

- 팀 계정에 등록한 단어집 72개(2,040줄)를 확인했습니다. 발음 칸(SoundsLike·IPA)과 표시 칸(DisplayAs)은 모두 비어 있습니다.
- AWS 공식 문서 기준으로 발음 칸은 지원이 종료되어, 값을 넣어도 무시됩니다.
- 숫자는 등록할 때 한글 읽기로 바꿨습니다(예: 중2층 → 중이층).

**2. 받아쓰기 → 서버 교정 → 언어 모델 보정 단계별 시험**

**결론: 서버 교정 뒤에 Claude Haiku 5.5를 붙이고 출력 형식을 강제하면, 측정한 10개 조건 모두에서 지금보다 같거나 좋아졌습니다. 대신 문장마다 약 1.4초가 더 걸립니다.**

| 항목 | 내용 |
|---|---|
| 데이터 | 조용한 녹음 180문장, 소음 합성 7조건(웅성거림 20/10/5/0 dB, 옆 사람 10/5/0 dB), 경복궁 현장 녹음 2개(126초) |
| 받아쓰기 | 저장해 둔 Amazon Transcribe 결과 (위치별 단어집) |
| 서버 교정 | 지금 서버 코드 그대로 (자주 틀리는 표기 표 + 위치별 교정 사전) |
| 언어 모델 | LFM3 1.7B (로컬), Claude Haiku 5.5 (Claude API). 같은 지시문과 같은 위치별 용어 목록을 넘김 |
| 순서 | "서버 교정 → 언어 모델", "언어 모델 → 서버 교정" 두 가지 |

### 결과물

**구성별 비교 (조용한 녹음 180문장)**

| 구성 | CER (%, ↓ 낮을수록 좋음) | 전각명 인식률 (%, ↑ 높을수록 좋음) | 지금보다 나빠진 조건 (10개 중) | 문장당 추가 시간 (초, ↓) |
|---|---|---|---|---|
| 지금 (서버 교정만) | 3.74 | 96.2 | — | 0 |
| 서버 교정 → LFM3 1.7B | 7.91 | 97.0 | 8 | 약 0.4 |
| 서버 교정 → Haiku 5.5 | 4.58 | 98.5 | 1 | 약 0.9 |
| 서버 교정 → Haiku 5.5 (출력 형식 강제) | **2.87** | **99.2** | **0** | 약 1.4 |

**조건별 CER (%, ↓ 낮을수록 좋음): 지금과 "서버 교정 → Haiku 5.5 (출력 형식 강제)"**

| 조건 | 지금 (서버 교정만) | 서버 교정 → Haiku 5.5 |
|---|---|---|
| 조용함 | 3.74 | 2.87 |
| 웅성거림 20 dB | 3.91 | 2.84 |
| 웅성거림 10 dB | 4.47 | 3.76 |
| 웅성거림 5 dB | 9.13 | 7.31 |
| 웅성거림 0 dB | 40.44 | 38.08 |
| 옆 사람 10 dB | 8.28 | 7.42 |
| 옆 사람 5 dB | 24.43 | 23.23 |
| 옆 사람 0 dB | 62.09 | 61.43 |
| 현장 녹음 1 (72초) | 4.46\* | 4.46 |
| 현장 녹음 2 (54초) | 9.21\* | 8.77 |

\* 서버의 '자주 틀리는 표기' 표에는 현장 녹음에서 나온 오류가 들어 있어, 현장 녹음의 서버 교정 수치는 실제보다 좋게 나옵니다.
{: .note }

- **LFM3 1.7B는 순서와 상관없이 지금보다 나빠졌습니다.** 용어 목록을 문장에 쏟아내거나 문장을 다시 쓰는 출력이 많았습니다.
- **Haiku 5.5는 출력 형식을 강제해야 안정적이었습니다.** 강제하기 전에는 고친 문장 대신 설명을 내놓는 출력이 29건 있었습니다. 답을 JSON 한 칸으로 강제하자 이런 출력이 사라졌습니다.
- **중간발표 뒤 나온 '임진왜란' 오인식이 고쳐졌습니다.** 조용한 녹음에서 "임진왜한테 소실됐다가"가 "임진왜란 때 소실됐다가"로 바뀌었습니다.
- **순서는 서버 교정을 먼저 두는 쪽이 조금 더 좋았습니다.** 형식 강제 후 10개 조건 중 6개에서 더 낮았고, 언어 모델을 먼저 두면 현장 녹음 1에서 오히려 나빠졌습니다(4.46% → 5.41%).

### 막힌 점 / 해결

- **서비스와 같은 GPT-6 Luna로 재지 못했습니다.** 팀 AWS 계정의 Bedrock에서 호출하면 "이 계정에서는 쓸 수 없음"으로 거절됩니다. IAM 권한 문제가 아니라 AWS가 계정에 모델을 열어 주지 않은 상태로, AWS 지원 요청이 필요합니다. 대신 Claude API의 Haiku 5.5로 측정했습니다.
- **소리가 많이 뭉개진 조건(0~5 dB)에서는 Haiku 5.5도 내용을 지어내는 경우가 있었습니다.** 약 2,900번 호출 중 4건이고, 연도를 바꾸거나 원래 없던 문장을 덧붙였습니다.
